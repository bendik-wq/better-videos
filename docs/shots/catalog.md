# Shot catalog: 200 named camera moves

Generated by `node docs/shots/build-catalog.mjs` from the same entries as `catalog.json` (machine-readable, used by the `shot-design` skill). Every recipe is a real `engine/camera.js` expression, evaluated against the shot-lab handles and smoothness-tested (`node projects/shot-lab/test-camera.mjs --catalog`). Emotional grammar and sources: `docs/shots/camera-language.md`.

**How to use a recipe.** `W` is the episode's handle object (same names as `projects/shot-lab/world-handles.mjs`: `W.hero`, `W.car`, `W.figure`, ...). Build the move once per set, then in `update(t)`: `M.apply(camera, move.at(t), { fx })`. Stretch to the shot with `M.retime(move, shot.duration)`. Chain with `M.seq([...])` for oners.

**Fields.** *Use*: the emotion or job. *Purpose*: beat jobs for shot-design. *Scale / energy*: for the alternation rule. *Lens*: focal length (full-frame mm). *Dur*: usable range in seconds. *Cost*: T1 <= 300 ms/frame, T2 300-450, T3 > 450 (1080p, llvmpipe). *Sets*: scenes it suits.
