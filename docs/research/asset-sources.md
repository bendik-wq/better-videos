# Free asset sources for a monetised YouTube channel

What we can pull programmatically into `assets/` and use in a **monetised** video. Checked on
2026-10-07. Licences change, so re-check the licence page before a big pull and record each
asset in the episode's credits file (see "Bookkeeping" below). This is a practical summary, not
legal advice.

**Legend:** ✅ safe by default · ⚠️ usable with conditions · ⛔ avoid for this channel.
"Verified" means we hit the URL pattern from this machine and got real data back.

## 3D: HDRIs, textures, models

| Source | What's there | Licence | Attribution | How to fetch |
|---|---|---|---|---|
| ✅ **Poly Haven** · https://polyhaven.com | HDRIs (to 16k+, .hdr/.exr), PBR textures, ~glTF models | **CC0** for assets. Logos, renders and site text are excluded. The ToS forbid scraping, so use the API ([licence](https://polyhaven.com/license)) | Not required. Apps built on the live API must say "Powered by Poly Haven" ([API README](https://github.com/Poly-Haven/Public-API)) | **Verified.** List: `https://api.polyhaven.com/assets?t=hdris|textures|models`. Files: `https://api.polyhaven.com/files/<id>` returns JSON with direct URLs. HDRI pattern: `https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/<res>/<id>_<res>.hdr` (res = `1k`,`2k`,`4k`,`8k`). Texture: `.../Textures/jpg/<res>/<id>/<id>_diff_<res>.jpg` (also `nor_gl`, `rough`, `arm`, `disp`). Model: read `files[<id>].gltf[<res>].gltf.url` plus its `include` map (bin plus textures). Our HDRIs (`moonless_golf`, etc.) come from here. Use 2k for IBL; SwiftShader PMREM is slow on 8k. |
| ✅ **ambientCG** · https://ambientcg.com | PBR materials, HDRIs, some models and decals | **CC0** ([licence](https://docs.ambientcg.com/license/)) | Not required. Suggested credit: "Created using <asset> from ambientCG.com, licensed under CC0 1.0" | **Verified.** Metadata: `https://ambientcg.com/api/v2/full_json?id=<AssetId>&include=downloadData`. Zip: `https://ambientcg.com/get?file=<AssetId>_<1K|2K|4K>-<JPG|PNG>.zip` (302 to a CDN). The API isn't promised to be stable ([API docs](https://docs.ambientcg.com/api/)), so cache zips locally. |
| ✅ **Kenney** · https://kenney.nl/assets | Low-poly kits (city, space, nature, vehicles), UI, some audio | **CC0** ([support](https://kenney.nl/support)) | Not required. Don't use the Kenney logo. | Per-pack zip from the asset page. Download links carry a changing hash, so download by hand into `assets/vendor/kenney/<pack>` and commit the glTF/GLB we use. |
| ✅ **Quaternius** · https://quaternius.com | Low-poly packs: characters (rigged and animated), nature, buildings, vehicles | **CC0** ([FAQ](https://quaternius.com/faq.html)) | Not required | Pack zips (FBX/OBJ/glTF/.blend) from the site. Convert FBX to GLB in Blender if needed. Also mirrored with an API on poly.pizza, which mixes CC0 and CC-BY, so check each model. Its rigged CC0 characters are an alternative to Mixamo. |
| ⚠️ **Mixamo** (Adobe) · https://www.mixamo.com | Rigged characters and ~2,000 mocap animations, FBX | Adobe terms: royalty-free in any creative project (films and games included). **You may not distribute the raw character or animation files.** No ML training. Needs an Adobe login. Secondary sources say the terms can change ([Adobe community FAQ copy](https://community.adobe.com/t5/mixamo-discussions/mixamo-faq-licensing-royalties-ownership-eula-and-tos/m-p/13234775)) | Not required | Manual: download FBX "without skin" for animation-only clips. Retarget in Blender, export GLB. **No public API**, so don't script logins. ⚠️ `assets/models/Soldier.glb` and `Xbot.glb` (from three.js examples, Mixamo-derived) are **committed to git**. If this repo is ever public, that's arguably raw-file redistribution. Move them to a git-ignored `assets/vendor/` with a fetch script. |
| ⚠️ **three.js example models** · `https://raw.githubusercontent.com/mrdoob/three.js/r169/examples/models/gltf/<file>` | Soldier, Xbot, Horse, Flamingo, LittlestTokyo, etc. | The three.js code is MIT, but **models have mixed origins** (Mixamo, Sketchfab CC-BY, etc.). We found no per-model licence file ([search notes](https://skills.sh/opusgamelabs/game-creator/game-3d-assets)) | Assume the original creator's licence | **Verified** (`Soldier.glb` returns 200). Fine for look-dev. Before shipping, trace each model to its origin. |
| ⚠️ **Sketchfab** · https://sketchfab.com | Over 700k downloadable models | Each downloadable model has a CC licence: CC0, CC-BY, BY-SA, BY-ND, BY-NC, BY-NC-SA, BY-NC-ND. **Only CC0 and CC-BY (and BY-SA with care) suit a monetised channel. Avoid every NC licence. ND means no modification, and re-texturing counts.** Store or "Standard" purchases fall under the separate store licence ([store licences](https://sketchfab.com/licenses)) | CC-BY: credit the author and Sketchfab, with the model link ([API guidelines](https://sketchfab.com/developers/download-api/guidelines)) | **Verified search.** `https://api.sketchfab.com/v3/search?type=models&q=<q>&downloadable=true&license=cc0` (slugs: `cc0`, `by`, `by-sa`, …; list at `https://api.sketchfab.com/v3/licenses`). Download: `GET https://api.sketchfab.com/v3/models/<uid>/download` with `Authorization: Token <API token>` (from account settings). Apps for other users need OAuth2. Returns signed glTF/GLB/USDZ URLs that expire. Record `license.label` and `user.username` from the model JSON. |
| ✅ **Smithsonian Open Access** · https://www.si.edu/openaccess | Millions of 2D/3D items, including 3D scans (GLB) via 3d.si.edu | **CC0** for items marked CC0. Check the item flag. | Not required | API via api.data.gov key: `https://api.si.edu/openaccess/api/v1.0/search?q=<q>&api_key=<key>`. *(The page returned 403 to our fetcher, so this is from prior knowledge. Verify the per-item `usage.access == "CC0"`.)* |
| ✅ **Solar System Scope textures** · https://www.solarsystemscope.com/textures/ | Planet, Moon, Sun and star maps, 2k to 8k | **CC BY 4.0** | Required: "Textures: Solar System Scope (CC BY 4.0)" | Links on the page follow `/textures/download/<res>_<body>.jpg` (e.g. `8k_earth_daymap.jpg`), but scripted requests got a 202 bot-check page from this machine. Download by hand. |

## Archive imagery and video

| Source | What's there | Licence | Attribution | How to fetch |
|---|---|---|---|---|
| ✅ **NASA Image and Video Library** · https://images.nasa.gov | Photos, video, audio | Generally **not copyrighted** in the US. **But** the NASA logos are protected, the material must not imply endorsement, identifiable astronauts or employees can't be used to promote anything, and third-party items are marked © ([guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/)) | Credit "NASA" (and the centre) | **Verified.** Search: `https://images-api.nasa.gov/search?q=<q>&media_type=image|video`. Asset list: `https://images-assets.nasa.gov/image/<nasa_id>/collection.json` gives `<nasa_id>~orig.jpg`, `~large.jpg`, etc. No key needed. |
| ⚠️ **Library of Congress** · https://www.loc.gov | Photos (FSA/OWI, news), maps, posters, film | **Rights vary per item.** The "Free to Use and Reuse" sets are curated as rights-free ([free-to-use](https://www.loc.gov/free-to-use/)). Everywhere else, read the item's *Rights Advisory* field. | Courtesy credit: "Library of Congress, Prints & Photographs Division, [reproduction number]" | **Verified.** JSON for any page: append `fo=json`, e.g. `https://www.loc.gov/photos/?q=<q>&fo=json`. Item JSON `https://www.loc.gov/item/<id>/?fo=json` has `image_url` and `rights_advisory`. Keep only "No known restrictions". |
| ⚠️ **Wikimedia Commons** · https://commons.wikimedia.org | Anything, with PD and CC files mixed | **Per file.** PD files are free. CC-BY needs attribution. CC-BY-SA needs attribution, and a modified file must keep the licence. Personality and trademark rights still apply ([reuse guide](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)). | Credit the author (not the uploader), the licence and a link. In video, a credit card or the description counts as "reasonable to the medium". | Scaled file: `https://commons.wikimedia.org/wiki/Special:FilePath/<File_name>?width=1920`. Licence metadata: `https://commons.wikimedia.org/w/api.php?action=query&titles=File:<name>&prop=imageinfo&iiprop=url|extmetadata&format=json` (`LicenseShortName`, `Artist`). **Send a descriptive `User-Agent` with a contact.** Without one we were rate-limited immediately. |
| ⚠️ **US National Archives (NARA)** · https://catalog.archives.gov | Federal photos and film (often PD as US-government works) | Most federal works are PD, but check each record for third-party rights. The API terms require a "not endorsed by NARA" notice in apps ([API help](https://www.archives.gov/research/catalog/help/api)). | Courtesy credit "National Archives" | API key (request it, 10k queries/month). No bulk scraping; use the AWS Open Data dataset for bulk pulls. |
| ⚠️ **Pexels** · https://www.pexels.com | Stock photo and video | Free, modifications allowed, attribution not required. **Not allowed:** identifiable people shown in a bad light, implying endorsement, selling unaltered copies, redistributing on stock sites, use as a trademark ([licence](https://www.pexels.com/license/)) | Not required | API key: `https://api.pexels.com/v1/search?query=<q>` with header `Authorization: <key>`. Videos via `/videos/search`. ⚠️ Stock people in a crime or fraud story count as a "bad light" risk. Use silhouettes, or crop the faces out. |
| ⚠️ **Pixabay** · https://pixabay.com | Stock photo, video, music, SFX | Free, no attribution. **Not allowed:** standalone redistribution, commercial use of content showing **recognisable trademarks or logos**, deceptive use, and identifiable people in immoral or illegal contexts ([licence summary](https://pixabay.com/service/license-summary/)) | Not required | API key: `https://pixabay.com/api/?key=<key>&q=<q>`. ⚠️ [house, unverified] Creators report third-party Content ID claims on stock music, so keep the download page and licence record for disputes. |

## Sound

| Source | What's there | Licence | Attribution | How to fetch |
|---|---|---|---|---|
| ⚠️ **Freesound** · https://freesound.org | ~600k+ SFX and field recordings | **Per sound:** CC0, CC-BY or CC-BY-NC (plus legacy Sampling+). **Filter to CC0 and CC-BY. NC is out for a monetised channel** ([FAQ](https://freesound.org/help/faq/)). | CC-BY: credit the sound name, author, link and licence. A linked credits page is acceptable. | API v2: get a token at `https://freesound.org/apiv2/apply`. Search `https://freesound.org/apiv2/search/text/?query=<q>&filter=license:"Creative Commons 0"&fields=id,name,username,license,previews&token=<key>`. **Previews** (`previews["preview-hq-mp3"]`, ~128 kbps) work with a token. **Originals** (`/apiv2/sounds/<id>/download/`) need OAuth2 ([auth docs](https://freesound.org/docs/api/authentication.html)). HQ previews are fine under a ducked mix. |
| ✅ **Sonniss GDC Game Audio Bundle** · https://sonniss.com/gameaudiogdc | Tens of GB of pro SFX, released yearly | Royalty-free commercial use, YouTube explicitly allowed, no attribution. **No AI/ML training. Don't redistribute the raw files** ([page](https://sonniss.com/gameaudiogdc)). | Not required | Manual torrent or zip, into a git-ignored `assets/vendor/sfx/`. |
| ⛔ **BBC Sound Effects** · https://sound-effects.bbcrewind.co.uk | 30k+ archive SFX | RemArc licence: personal, educational and research use only *(from prior knowledge, not re-checked)* | n/a | Avoid for a monetised channel unless you buy a commercial licence. |
| ✅ **Our own** `engine/score.py` | Procedural drone and cue synthesis | Ours | n/a | Preferred for drones, hits and risers. No licence risk and no Content ID claims. |

| Source | Licence | Notes |
|---|---|---|
| ✅ **Google Fonts** · https://fonts.google.com (Instrument Serif, IBM Plex Mono, Archivo Narrow are all here) | Mostly **SIL OFL 1.1**, some Apache 2.0. ## Bookkeeping [house]

1. Put every third-party file under `assets/vendor/<source>/…` and log it in
   `assets/CREDITS.json`: `{file, source_url, licence, author, attribution_text, fetched}`.
2. A render step should collect the credits for every asset a project actually loads and write
   `projects/<name>/out/CREDITS.txt` for the YouTube description. CC-BY, OSM and Solar System
   Scope credits are **mandatory**. The others are courtesy.
3. Only CC0, PD, CC-BY and BY-SA (BY-SA only for unmodified or separate assets) go into
   monetised videos. **Never NC or ND.**
4. Raw Mixamo, Sonniss and Pexels/Pixabay files should not sit in a public git repo. Keep them
   in git-ignored vendor folders with a fetch script.
5. Archive photos of identifiable private people: prefer silhouettes or crops. That's a style-bible
   rule anyway (no realistic CG humans), and it removes publicity-rights risk.
