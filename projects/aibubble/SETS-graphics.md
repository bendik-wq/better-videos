# AI-bubble graphics sets (2D): parameters and cues

Libraries loaded by `scene.js` (`LIBS`): `sets/graphics.js`, `sets/graphics-data.js`, `sets/graphics-maps.js`,
`sets/graphics-docs.js`. Shared helpers live in `sets/graphics-kit.js` (no sets): palette, fonts, the canvas set, camera
drift, the Nasdaq key closes (`NASDAQ`) and an image loader. Every set paints a 2D canvas at 1920×1080 units as a pure
function of t (seeded noise only). Adapted from `projects/silver/sets/graphics*.js`; all silver content is gone.

Look-dev: `projects/aibubble-gfx-lab` (one shot per set/mode, no narration):
`node engine/render.mjs projects/aibubble-gfx-lab --stills=0.3,0.9` (filter with `ONLY=id,id`) → `projects/aibubble-gfx-lab/out/stills/`.

**House style.** Bright paper `#f7f6f1` with faint teal ledger rules, ink navy `#14233d`, sage `#a9c5ae` / teal `#2a8c86`,
ONE red `#e0241b` per frame for the thing that matters. Figures Plex Mono, headlines Inter 800–900, quotes and filings
Instrument Serif, filing labels Archivo Narrow. ⏱ figures carry a navy **AS OF** pill; computed numbers a mint
**OUR MATH** pill. Recreated filings say so on screen ("RECREATED TEXT · …"). Key-price charts say "DOTS = KEY CLOSES ·
NOT A DAILY SERIES · STRAIGHT LINES JOIN THE DOTS". No chart says "crash" (RESEARCH §14).

**Cues.** Anything called `at`, `word`, `…At` takes seconds into the shot or a spoken word: `'Oracle'`, `'hundred@1'`
(2nd time said), `'circle+0.3'`. Unknown words fall back to defaults, so every set runs a full animation without VO.
**Camera.** Every set drifts/pushes slowly; override with `params.cam = { push, dx, dy, fx, fy }` (push 0 = locked).
**Sources.** Every set prints its own source line; `params.source` replaces it; `kicker` / `title` replace the top lines.

## Data

- Nasdaq key closes: `NASDAQ` in `sets/graphics-kit.js`; chart points in `LINES` / `PANELS` (graphics-data.js), each with its RESEARCH row.
- Deal edges: `EDGES` in `sets/graphics-maps.js` (ids = RESEARCH §2a C-numbers).
- `assets/geo/world.json`: Natural Earth 1:50m (public domain), copied from the silver build: `world` (ISO3), `us` ('US-XX' + CAN/MEX/CUB/BHS/GTM), `lakes`. Rebuild: `python3 -I projects/aibubble/assets/geo/build.py <natural-earth geojson dir>`.
