# Palomares graphics sets (2D): parameters and cues

Libraries loaded by `scene.js` (`LIBS`): `sets/graphics.js`, `sets/graphics-data.js`, `sets/graphics-maps.js`,
`sets/graphics-docs.js`. Shared helpers live in `sets/graphics-kit.js` (no sets): palette, fonts, the canvas set, camera
drift, the **seabed section** (the episode's depth motif: `DEPTH`, `SEABED`, `UPOS`, `section()`, `drawSection()`, `bomb()`,
`ship()`, `fence()`, `pulse()`) and an image loader. Every set paints a 2D canvas at 1920×1080 units as a pure function of t
(seeded noise only, eased, slow camera drift). Adapted from `projects/aibubble/sets/graphics*.js`; all AI-bubble content
(Nasdaq closes, ai-chart, SEC filings, dealmap) is gone.

Look-dev: `projects/palomares-gfx-lab` (one shot per set/mode/doc/photo, no narration):
`node engine/render.mjs projects/palomares-gfx-lab --stills=0.3,0.9` (filter with `ONLY=id,id`) → `projects/palomares-gfx-lab/out/stills/`.

**House style.** Bright paper `#f7f6f1` with faint teal ledger rules, ink navy `#14233d`, sage `#a9c5ae` / teal `#2a8c86`,
ONE red `#e0241b` per frame for the thing that matters. Figures Plex Mono, headlines Inter 800–900, quotes and documents
Instrument Serif, labels Archivo Narrow. ⏱ facts carry a navy **AS OF** pill; computed numbers a mint **OUR MATH** pill.
Recreated documents say so on screen ("RECREATED TEXT · …" / "RECREATED SUMMARY · …"). Sections say "SCHEMATIC, NOT TO
(HORIZONTAL) SCALE"; reconstructed geography says "RECONSTRUCTION" / "ILLUSTRATIVE".

**Cues.** Anything called `at`, `word`, `…At` takes seconds into the shot or a spoken word: `'Alvin'`, `'found@1'`
(2nd time said), `'parted+0.3'`. Unknown words fall back to defaults, so every set plays a full animation without VO.
**Camera.** Every set drifts/pushes slowly; override with `params.cam = { push, dx, dy, fx, fy }` (push 0 = locked).
**Sources.** Every set prints its own source line; `params.source` replaces it; `kicker` / `title` replace the top lines.

## Data notes

- **Depths** (`DEPTH` in graphics-kit.js): rim 2,130 ft (355 fathoms), found 2,550 ft, re-found 2,800 ft: S01 p.94 ✓. Lift ~2,850 ft: S40 + NRDC caption ⚑. "+250 FT DEEPER" (D35), never 300. Pinnacle's ~2,000 ft hits are in `DEPTH.pinnacle` but not drawn.
- **The section** (`SEABED`) is schematic: shape after RESEARCH §11.3 (shelf, 200 m break, canyon wall, plain), not to horizontal scale; every section says so.
- **Times**: collision ~10:22 local (0922Z, S01 ✓); line parted "about 9:15 pm" per Moran (S41, Gap-fill G1 ⚑, attributed on screen); "Weapon on deck" 08:46 (Petrel log via Moran ⚑, attributed).
- **Day counts**: days *after* the crash; 7 Apr = 80 (READ FIRST 7, D34); 2 Mar = 44 matches the DoD text's "44 days".
- **Compare marks** on `depth` (⚑ S52 via S100 / S40): divers 120 / 350 ft, Cubmarine 600 ft, Deep Jeep 2,000 ft. No Empire State Building comparison: RESEARCH gives no building height, so there is no sourced math to show; "About half a mile down" is RESEARCH's own VO guidance (D31).
- **Geography**: `assets/geo/world.json` (Natural Earth 1:50m, PD; rebuild `python3 -I projects/palomares/assets/geo/build.py <NE geojson dir>`; adds an `iberia` layer). `assets/geo/almeria.json` + `almeria-relief.png` (rebuild `python3 -I projects/palomares/assets/geo/build_coast.py <NE dir> assets/geo/emodnet-grid.json`): coastline Natural Earth 1:10m (PD); isobaths in feet and land relief from the **EMODnet Bathymetry DTM (CC BY 4.0, credited on screen)**, sampled via its REST API into `emodnet-grid.json` (0.002° rows × 241 columns, 37.02–37.46 N, 2.05–1.45 W). EMODnet's own coast is ~1 km off at the Almanzora mouth, so it is used offshore only. The research bathymetry grid (S38) is kept as `assets/geo/palomares_bathy_grid.csv` (RESEARCH open item 15).
- **Coast-map reconstructions**: bomb 4's find area = the canyon box in §11.3 (37.165–37.185 N, 1.71–1.74 W); bomb 1 = inferred point (§11.7 ⚠); bombs 2/3 = CSN zone centroids; the Almanzora course is hand-placed (north and east of the village to the mouth at 37.242 N, 1.775 W); the 51-sq-mi wedge is drawn as a 90° sector of 12.97 km from the Almanzora mouth (area per Moran ⚑, shape ours, labelled).
- **⏱ re-check before VO lock / publish**: fence still up and "AS OF 21 OCT 2026" (chapter `today`, timeline last event), the court status (`court2026`, timeline), no binding US–Spain agreement (timeline 2015 label).
- **Never on screen** (RESEARCH §13): RI/FI variants (photo file names contain them; captions must not), "300 ft deeper", "two tons", Savannah River "Georgia", Alvin yellow, an Alvin lamp on 24 Mar (the `depth` and `title` sets show no Alvin at the loss).
