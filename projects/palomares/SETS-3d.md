# Palomares (ep 9) 3D sets: `sets/pal-sets.js`

Reconstructed-channel look: white glossy models, painted-sky dioramas (`paintedSky`), soft shadows, one red accent (#e0241b).
Every set is `async (ctx, shot) => { scene, camera, layer, update(t) }` and is a pure function of t.
Look-dev project: `projects/palomares-lab` (one shot per set and mode; `ONLY=id,id node engine/render.mjs projects/palomares-lab --stills=0.3,0.6,0.9`, `W=960` for small stills).

**Common params (all sets):**
- `camera`: `[{ pos, look, mm }]` keys (S.rig). Each mode has its own default.
- `caption`: black-slab caption. Pass `null` for none; each mode has a default.
- `source`: source line, bottom right. Pass `null` for none.
- `pills`: `[{ text, at, until, target, red }]`. `target` is a named target or `[x,y,z]`.
- `seed`: painted-sky seed.
- `quality`: post quality (`medium`).

Cues (`at`, `until`, `xAt`…) take seconds or spoken words (`'word'`, `'word@2+0.3'`, `{ word, at }`).

Shared builders exported from `pal-sets.js`:
- B28 and the outline: `b28()`, `dashedOutline(poly)`, `B28`.
- Chute: `canopy({ r, h, gores })` with `.set({ breath, squash })`.
- Aircraft: `b52()`, `kc135()`.
- Sea vehicles and ships: `alvin({ pilots })`, `curv()`, `ship({ kind: 'navy' | 'mizar' | 'petrel' })`, `trawlerBoat()`.
- Utilities: `rods(n)` (instanced lines).

House rules applied:
- No floor surface sits at y=0 under a visible cyc. Sky sets hide the cyc and sit on thick discs, slabs or blocks.
- Every label plane is billboarded or alpha-tested.
- Decals use polygonOffset.
- Pills are projected after the S.rig update.
